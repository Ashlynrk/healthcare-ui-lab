# Healthcare UI Lab

A calm sample health companion for practicing product design and front-end engineering. The people, visits, and medications are fictional. Entries stay in this browser and are not a medical record or advice.

## Run the app

```bash
npm install
npm run dev
```

Open the local address Vite prints, usually http://localhost:5173.

## Original prototype

The first HTML page is preserved at `reference/today.html`. Open that file directly in a browser to see the starting point. The React app does not replace it.
